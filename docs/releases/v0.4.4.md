## 주요 변경

- **글씨 우선 모드와 30/60fps 선택을 분리**했습니다. 기존 0.4.3의 글씨 우선 설정은 글씨 우선 + 30fps로 유지됩니다.
- **가상 확장 디스플레이에 기기별 해상도 목록, 방향, Windows 배율, 커스텀 해상도 설정을 모았습니다.** 전송 영역에서는 품질과 프레임만 선택합니다.
- 1280×800 등 선택한 해상도를 Windows 확장 화면에 적용한 뒤 진행 중인 캡처도 갱신합니다.
- 오른쪽 설정 영역 때문에 왼쪽 설명이 세로로 쪼개지던 배치를 수정했습니다.

## 프레임 설정과 성능 개선

- 캡처 시작 도중 변경한 설정이 누락될 수 있는 문제를 수정했습니다.
- 선택한 프레임률을 캡처에 명시적으로 요청하고, 전송 설정 적용 실패를 숨기지 않고 표시합니다.
- 전송 중 PC 미리보기를 일시 정지하고 마지막 수신 연결이 종료되면 다시 표시합니다.
- 태블릿 통계·버튼의 배경 흐림 효과를 제거하고 연결 후 페어링 창을 완전히 숨깁니다.
- 통계가 숨겨진 동안 표시 문구 갱신을 생략합니다. PC 진단용 통계 수집은 유지합니다.

## 진단 통계 추가

- 태블릿·PC: 실제 수신 해상도, 화면 멈춤 누적 횟수·시간, 최근 프레임 출력 간격 평균·최대.
- PC: 캡처 설정/실제 FPS, 송신 상한/실제 FPS, 수신 FPS, 브라우저가 보고한 품질 제한 사유.
- 미지원 항목은 미지원으로, 출력 간격 표본이 없는 경우 측정 대기로 표시합니다.

출력 간격은 화면 합성 제출 시각 기준의 근사치이며 실제 패널 출력 시각의 정밀 측정은 아닙니다. 정지 화면에서는 FPS가 낮아질 수 있으므로 같은 움직이는 화면에서 비교하세요. 실제 60fps 달성 여부와 개선 정도는 PC·태블릿·네트워크에 따라 달라집니다.

## 사용 방법

1. 설치 후 태블릿의 수신 페이지를 새로고침합니다.
2. 가상 확장 디스플레이에서 기기 또는 해상도·방향·배율을 선택하고 **해상도·배율 적용**을 누릅니다. 관리자 승인이 필요하며 화면이 잠시 끊길 수 있습니다.
3. 전송 품질과 **30fps / 60fps**를 각각 선택합니다.
